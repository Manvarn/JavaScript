-> Callback - A callback is a function that is passed into another function as an argument and is executed after the completion of an asynchronous operation.

-> What is a Callback? A callback is simply a function that you pass as an argument to another function, and that function gets called when the operation finishes. Callbacks are commonly used to handle asynchronous tasks like loading data, reading files, etc.

->  Synchronous - In synchronous execution, tasks are performed one after the other in a sequential manner. Each operation must complete before the next one starts. The program waits for one task to finish before starting the next.

-> Asynchronous - In asynchronous execution, tasks can run in parallel, meaning the program does not wait for one task to finish before starting another. The program moves on to the next task while waiting for other tasks (like fetching data or timers) to complete.

-> Promises - A Promise is an object that represents the eventual completion or failure of an asynchronous operation. It allows you to handle asynchronous code more cleanly and with better control by providing then(), catch(), and finally() methods. (A promise is like a placeholder for the result of an asynchronous operation.)

-- A Promise has three states:
	- Pending: The operation is still ongoing.	
	- Fulfilled: The operation complete	d successfully.
	- Rejected: The operation failed.

-> .then() is used to handle the successful result (when the promise is fulfilled).

-> .catch() is used to handle the error (when the promise is rejected).
 
-> .then() and .catch() handle the result or error accordingly.

-> The promise takes a function with two parameters: resolve and reject. 

-> resolve(value): when the task is successful. // reject(error): This is called when there is an error.

-> the resolve or reject is called after the 2 seconds, depending on whether the operation was successful.
